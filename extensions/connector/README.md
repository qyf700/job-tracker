# 求职工作台连接器 v0.4.1

在 Chrome/Edge 扩展管理页打开开发者模式，加载解压目录；工作台保持登录并打开。在“浏览器连接”生成配对码，扩展申请后回工作台核对权限并批准。

用真实材料确认快照，领取任务并打开知乎申请页。登录、验证码、官网协议由本人处理。重新核对目标页后，读取填写与上传预览，核对岗位、原件哈希和资料字段，勾选材料传输确认后分别操作。

建议先上传原件，等待官网解析完成，再次预览并填写空白字段。上传会将真实简历传给官网，可能触发解析；同一任务只授权一次，不自动重试。已有字段和文件不覆盖。学校/专业选项及未识别控件请本人处理。

逐项检查官网所有必填项、选项与附件后，可勾选复核并“停在最终提交前”。扩展没有最终提交命令；本人在知乎官网确认后操作“预览并提交”。状态仍不等于已投递。

网络/进程中断后禁止重复执行未知操作，只可重试状态回传；请本人核对官网。需要重做时重新确认新材料快照。保持工作台打开，120秒租约、30秒心跳、单次会话最长30分钟。

仅限核验过的知乎/Moka岗位。无全站、Cookie或webRequest权限，不读取验证码、登录Cookie或回传网页正文；冻结材料不持久化到扩展磁盘。实际官网控件和上传完成需本人现场验收，不能用后台测试替代。


v0.4 本地字段映射：扫描实际字段分组和控件类型，显示精确/别名匹配依据、冻结资料版本或本岗位答案来源；资料为空、字段未知、经历数量不一致时列出待处理项。已有值保留，不倒灌回工具。预览绑定页面结构，结构变化必须重新确认。SD 下拉只选择当前控件中的唯一选项，并等待实际显示值核验；日期有部分旧值时整组保留。上传入口状态未知或已有简历时禁止自动上传。参考项目及 MIT 许可见 THIRD_PARTY_NOTICES.md。
