# 官网填表助手（开发者安装版）

Chrome/Edge Manifest V3，权限仅 activeTab、scripting、storage。没有服务器请求、浏览历史读取、登录凭据读取或自动提交。

1. 从个人资料页导出 JSON，在扩展中导入（仅保存本机）。
2. 打开实际简历表单，点击扩展扫描。逐项核对资料字段；含歧义的字段不会自动勾选。
3. 保存映射按当前域名/页面保存字段键，不存官网内容和查询参数。
4. 填入已选空白字段；已有内容、敏感认证字段和非原生控件跳过。
5. 官网新增/展开经历行后需重新扫描；不自动新增行、不操作验证码、不上传简历、不点击提交。

公司识别仅决定显示名称，并不表示完整表单通过实测。字节、腾讯等公司已建立识别入口；其登录后的实际表单仍需逐一验证。通用引擎支持可见原生 input/textarea/select、开放 Shadow DOM；跨域 iframe 不支持。自定义学校/城市下拉请手动处理。

扩展资料与云端不是实时同步；修改后重新导出导入。导出的文件含个人信息，请自行妥善保存。
